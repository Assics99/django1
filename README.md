# Пульт охраны банка

Это внутренний репозиторий для сотрудников банка «Сияние». Если вы попали в этот репозиторий случайно, то вы не сможете его запустить, т.к. у вас нет доступа к БД, но можете свободно использовать код вёрстки или посмотреть как реализованы запросы к БД.

Пульт охраны — это сайт, который можно подключить к удалённой базе данных с визитами и карточками пропуска сотрудников нашего банка.

## Как установить

1. Скачайте код.
2. Установите зависимости с помощью [Poetry](https://python-poetry.org):
   ```bash
   poetry install
   ```

## Переменные окружения

Для работы проекта необходимо создать файл `.env` в корне проекта и добавить настройки для подключения к базе данных и конфигурации Django:

* `SECRET_KEY` — секретный ключ Django-приложения.
* `DB_HOST` — адрес сервера базы данных.
* `DB_PORT` — порт для подключения к базе данных (обычно `5432`).
* `DB_NAME` — имя базы данных.
* `DB_USER` — имя пользователя для доступа к БД.
* `DB_PASSWORD` — пароль от базы данных.

## Как запустить

Для запуска скрипта выполните команду:
```bash
poetry run python main.py
```
